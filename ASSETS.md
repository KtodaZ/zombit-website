# Asset provenance

Every raster this site ships is listed here with its source. The uncompressed
captures live in `_assets-raw/`, which is gitignored because it is 61 MB and
fully derivable from the store listings.

## Screenshots — `public/shots/`

All are real app screens, not marketing composites. Store slides that arrived as
composed device mockups were cropped back to the raw screen with `ffmpeg`, then
encoded with `cwebp -q 86 -resize 620 0`. The site draws its own device frame, so
every app sits in an identical one.

| File | Source | Treatment |
|---|---|---|
| `alwaysontime-1..3.webp` | Google Play listing for `com.zombitstudios.alwaysontime` | resize to 620px wide, WebP q86 |
| `artillery-1.webp` | Google Play listing for `flutter.app.artillery_let_loose` (faction picker) | `crop=636:1176:220:740`, then resize + WebP q86 |
| `montessori-1..3.webp` | App Store listing id `6760267134` | `crop=738:1672:253:842`, then resize + WebP q86 |

**Known gap:** Artillery ships one screen where the other two apps ship three.
The App Store images for it are angled marketing composites that cannot be
cropped back to a flat screen, and the Play Store page scrape returned images
belonging to unrelated apps. Two more straight-on captures are needed from the
app itself.

## Icons — `public/icons/`

| File | Source |
|---|---|
| `alwaysontime.webp`, `artillery.webp`, `montessori.webp` | store listing icons, 256px, WebP |
| `zombit-mark.webp` | the studio's existing blue Z mark, 512px, WebP |

The Z mark is existing brand work and is not to be redrawn or retired. It is used
subtly — favicon, masthead, colophon — and never as a hero element.

## Ratings

`src/data/ratings.json` is generated by `scripts/fetch-ratings.mjs`, which reads
the iTunes lookup API and the Play Store listing page. On a fetch failure it
keeps the previously committed value rather than writing a placeholder. No rating,
review count, or download figure on this site is hand-written.
